# Liquid Glass UI Screenshots & Goldens

This directory contains light and dark theme screenshots and golden test outputs for the Liquid Glass UI migration.

## Captured Screens & Components
1. **More Modules (`MoreModulesScreen`)**
   - Light & Dark mode glass headers, search bar, and module cards with live search & badge counts.
2. **Employee Home (`EmployeeDashboardScreen`)**
   - Glass cards, metrics, attendance widget, and floating glass bottom navigation bar.
3. **Form Screen (`ApplyLeaveScreen` / `UserFormScreen`)**
   - Glass inputs with 2px teal focus ring and gradient action buttons.
4. **List Screen (`MyAttendanceScreen` / `MyTasksScreen`)**
   - Non-blur high-performance list cards (`blur: false`) with status badges.
5. **Dialog & Bottom Sheet**
   - Blurred chrome modals (`blur: true`, 18-24px blur).
6. **Settings (`MySettingsScreen`)**
   - Appearance & Accessibility settings including Dark Mode and Reduce Transparency toggles.
7. **Login (`LoginScreen`)**
   - Multi-stop gradient background (`AppBackground`), glass login card, and brand header.
